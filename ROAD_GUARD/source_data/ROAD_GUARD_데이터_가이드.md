# ROAD GUARD 전처리 데이터 가이드

## 목적
국립공원공단에서 공개한 **국립공원 로드킬 기록**을 ROAD GUARD 역사적 기록 지도와 시연에 사용할 수 있도록 정리한 데이터 패키지.

## 원본 및 검증 결과
- 원본: `국립공원공단_국립공원 로드킬 정보_20231220.csv` (원본 문자 인코딩: CP949)
- 기록: **3,183행** / 유효한 기록: **3,183행** / 제외: **0행**
- 기간: **2011-01-10 ~ 2023-11-20**
- 국립공원 **20곳**, 동물명 **98종**, 고유한 국립공원-좌표 쌍 **95곳**
- 완전 동일한 정보의 중복 후보: 추가 행 **307개**, 그룹 **236개**. 중복 확정 불가능하여 삭제하지 않음.
- 원본에 결측/날짜 해석 불가/한국 범위 밖 좌표가 없었음.

## 파일 설명
- `roadguard_roadkill_clean.csv` : 전처리 상세 데이터 (UTF-8 BOM, 엑셀 열기 쉬움). **전체 원본 행 보존**.
- `roadguard_records.json` : 동일 데이터의 웹 앱용 JSON. 필터와 기간별 분석에 적합.
- `roadguard_sites.csv` : 좌표별 기록 건수와 최빈 동물명 요약 (UTF-8 BOM).
- `roadguard_sites.geojson` : Leaflet 지도용 `FeatureCollection`. 각 지점은 `[경도, 위도]` 좌표의 Point. `species_counts`, `year_counts`, `year_species_counts` 포함.
- `roadguard_summary.json` : 원본 품질·통계·주의사항 보고서.
- `roadguard_preprocess.py` : 원본 파일에서 결과물을 재생성하는 스크립트.

## 정제 상세
1. CP949 인코딩 원본 읽기 → UTF-8 출력.
2. 공원명과 동물명 공백 정리, 조사일자 `YYYY-MM-DD` 확인.
3. 경도·위도를 **숫자 타입**으로 변환하고 국내 대략 범위(경도 124~132, 위도 33~39) 검증.
4. `year`, `month` 생성. `record_id`는 원본 행에서 만든 추적용 ID, `source_row`는 원본 CSV 행번호.
5. 공원명+경도+위도 단위로 `site_id` 부여. 동일 좌표 관측을 합산하여 지도 마커 수를 줄임.
6. 완전 동일 행은 **삭제하지 않고** 두 번째 등장 행부터 `is_duplicate_candidate=1`로 표시.
7. 종 분류/위험 점수/시군구는 원본에 없으므로 임의로 추가하지 않음.

## 컬럼 설명
- `record_id`: 원본 행별 구분자 (`RK-00001` 등)
- `source_row`: 원본 파일의 행 번호(헤더는 1행)
- `site_id`: 국립공원+동일 좌표별 집계 ID
- `park_name`: 국립공원명
- `observed_date`: 조사일자 (사고 발생시각이 아님)
- `year`, `month`: 조사일자에서 추출
- `species_name`: 자원명 (원본의 동물명)
- `longitude`, `latitude`: 원본 좌표 숫자
- `is_duplicate_candidate`: 완전 동일 정보의 앞선 행이 있으면 1, 아니면 0

## 매우 중요한 해석 주의
1. **같은 좌표에 여러 행**이 들어 있는 이유가 원본 설명에 없기 때문에, 마커는 **관측/기록 좌표별 기록 수**로 설명한다. 개별 사고 정확 위치나 위험 확률처럼 표현하면 안 된다.
2. **과거 로드킬 기록**을 **실시간 AI 감지** 또는 실제 위험도 예측과 혼동하지 말 것.
3. 지도에 국가공원별 기록이 있으나 **강릉시 행정구역 컬럼은 없다**. 강릉 사고 건수를 여기서 곧바로 계산하면 안 된다.
4. 카테고리마다 조사 규모와 기간이 다를 수 있으므로 공원 간 기록 건수 순위를 도로 위험 순위라고 해석하면 안 된다.
5. 실제 데이터 마커는 **파랑**, 실시간 탐지 체험용 **가상 센서/가상 경고**는 초록/주황으로 구분하고 '가상 시뮬레이션'을 표시한다.

## 다음 개발 순서
1. 웹 폴더 `data/`에 `roadguard_sites.geojson`과 `roadguard_records.json`을 복사.
2. Leaflet에서 `L.geoJSON(siteData, {pointToLayer: ...})` 로 **좌표별 마커** 표시, 팝업에 공원명·기록 건수·대표 동물·기간 표시.
3. 공원/연도/동물 필터는 `roadguard_records.json` 원본 행에 먼저 적용하고, 선택한 `site_id`별로 다시 집계한 뒤 지도 마커 갱신.
4. 가상 센서 3개는 별도의 JS 배열과 `L.layerGroup()`에 둔다. 실제 좌표 집계와 절대 합치지 않는다.
5. 교육 카드뉴스 및 영상은 파일 준비 후 웹페이지 영역에 연결.

## 웹페이지 실행 참고
브라우저 `file://` 직접 열기로는 `fetch('./data/...')`가 브라우저 보안 제한에 막힐 수 있다. 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000`을 열거나 GitHub Pages 등 정적 호스팅에 배포한다.
